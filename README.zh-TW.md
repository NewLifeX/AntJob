AntJob 是面向大數據的分散式作業排程平台，支援即時與離線任務分發、螞蟻搬家式分片運算、容錯移轉和視覺化管理。

## 安裝

```bash
dotnet add package NewLife.AntJob
```

## 快速開始

```csharp
var setting = new JobSetting { Server = "http://127.0.0.1:5000" };
var client = new JobClient(setting);
client.Start();
```

## 核心特性

- 高吞吐、低延遲，已在生產環境大規模驗證
- 與 NewLife 生態（XCode/Cube/Remoting）無縫整合
- 外掛化與可擴充架構，便於二次開發
